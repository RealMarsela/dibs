# Chain mark sources

Fetched 2026-11-17 with curl from the exact URLs below, then sanitized (scripts, foreignObject, metadata, comments, on* attributes and external hrefs removed; fixed width/height dropped; ids, gradient ids, clipPath ids and CSS class names prefixed with the brand name). Shapes and colours are unchanged.

| File | Source URL | Notes and terms |
|---|---|---|
| near.svg | https://raw.githubusercontent.com/near/docs/master/assets/logo.svg (official `near` GitHub org, docs repo) | The N logomark is the 5th path of the near wordmark file, kept alone with a tight viewBox (the four letter paths "near" are dropped). Mark is plain black with no fill set; recolour through CSS on a wrapper if a dark background needs it. near/docs is Apache-2.0 licensed. No separate brand-use terms were found: near.org/brand, /press and the old press-center brand-kit links return 404 or no asset. The older N used in near/wallet-selector is a previous mark. |
| base.svg | https://raw.githubusercontent.com/base/brand-kit/main/logo/TheSquare/Digital/Base_square_blue.svg (official Base brand-kit repo) | The Base Symbol is "The Square" (the repo README lists Base_square_* as Symbol). Source fill `blue` written as #0000FF. Terms: base.org/brand and guides/brand-guide.pdf in the repo; not read here. |
| solana.svg | https://raw.githubusercontent.com/solana-foundation/solana-com/main/apps/web/public/img/logomark-color.svg (official Solana Foundation repo; the logomark solana.com/branding serves) | One diagonal gradient across the three bars, as supplied. Repo is GPL-3.0. The solana.com/branding terms render client-side and could not be read with curl. |

Repo licence is NOASSERTION. |

| usdc.svg | `Token Logo/USDC Token.svg` inside https://6778953.fs1.hubspotusercontent-na1.net/hubfs/6778953/Pressroom/brandkit/logo-downloads/usdc.zip (the "Download USDC logos" link on https://www.circle.com/pressroom; guide at https://brand.circle.com/d/M9z54TaEwsWL/stablecoins) | The USDC Token Logo (circle with $).
